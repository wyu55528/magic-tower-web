# 魔塔 · 网页版（30 层完整塔）

[![verify](https://github.com/wyu55528/magic-tower-web/actions/workflows/verify.yml/badge.svg)](https://github.com/wyu55528/magic-tower-web/actions/workflows/verify.yml)
[![license](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

零构建、纯前端。**30 层塔**，最终魔王 **20 万血 / 2500 攻 / 800 防**，
主角的武器和防具各分 **5 档**，数值是从魔王倒推出来的，
并且用**无头求解器**自动跑通验证过。

塔里**没有药水**：加血只有即时性，血瓶一个都攒不下来。
商店还在 —— 卖的东西**全部当场生效**。

每层 **30 只怪**（全塔 900 只），但**没有两只怪挨着** —— 路上走一段遇一只，
不是一格接一格全是怪。

塔是**从下往上爬**的：第 1 层在塔底，第 30 层（魔王）在塔顶。

地图是 **13×13**，改成**「九间房 + 门洞」**的结构，不再是一片空旷的街区：

- 每层是 **9 间 3×3 的房**，被 1 格宽的墙分开（墙在第 4 / 8 行和第 4 / 8 列）；
- 房间之间只在墙上开**门洞**，一个门洞就是一条通路；
- 门洞的连法是一棵**有分叉的树** —— 3×3 的房间网格一共 192 种连法，30 层轮着来。

墙占 47.3%，平均每层空地 89 格；每层有 36 处 2×2 的**开阔地**、45 个**岔口**。
格子是直角，墙看过去是一块块方方正正的黑砖。

奖励都锁在**上锁的房**里 —— 每个门口都站着怪，不打怪就进不去。怪分两种站位：

- **看门怪**（守关怪 + 小鬼 + 史莱姆）守在**门洞**上，
  房间里放着钥匙、结晶、商店这类好东西。
- **巡逻怪**散在**房间里**（房角或房中心），每层 26 只。

怪之间**留空**：任何两只怪都不会上下左右相邻，
所以不会出现「一条道上每一格都是怪」。

## 怎么打开

**最省事：双击 `dist\魔塔-单文件版.html`。**

那个文件把这 30 层塔的全部代码（一份 CSS + 18 个 JS 模块）打包进了同一个 HTML，
不用装任何东西、不用起服务器，双击直接就能玩。
它是自动生成的：源码改完跑一次 `node tools/build-single.mjs` 就会重新生成。

**另一种：双击 `start.bat`。**

它会找一个可用的 Python，自动挑一个没被占用的端口
（8000 → 8001 → 8002 → 8003 → 8080），起一个只监听 127.0.0.1 的服务器，
再自动打开浏览器。局域网里的其它机器访问不到。

> 源码版 `index.html` 用了 ES Module，浏览器会拦截 `file://` 下的模块请求，
> 所以它必须配合服务器打开。直接双击它的话，页面会弹一张提示卡，
> 告诉你可以用上面两种办法。

## 一屏玩完，不用来回滚

页面按视口高度固定，**整页不会纵向滚动**：

- 顶栏一排：第 n 层 + 生命 / 攻击 / 防御 / 金币 / 步数 + 保存读取重开（血量没有上限，只写当前值）
- 左栏一列：装备、钥匙、背包，操作说明折起来（点一下就展开）
- 中间：地图在上，日志在下，日志自己滚

格子大小跟着窗口走（`--cell` 同时受宽高约束），窗口变小地图跟着缩，
格子永远不会撑破版面。侧栏内容多的时候只有侧栏内部会滚。

## 操作

| 键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| `↑` `↓` | 站在楼梯旁边（且背包里有传送卷轴）时上一层 / 下一层 |
| `1`–`9` | 使用对应道具；商店里买第 N 件 |
| 两位数 + `回车` | 选第 10 件及以后的（商店只有 3 件，目前用不上） |
| `B` | 打开怪物图鉴（第 1 层出口捡到） |
| `U` | 撤销一步 |
| `Esc` | 离开商店 / 合上图鉴 |

踩到怪物自动开战，踩到门自动扣对应钥匙，拾取装备立刻生效，
捡到生命结晶就直接加血（塔里的血量没有上限）；
商店里买的东西也是**当场生效**（回血立刻涨，磨刀石 / 护心镜直接加到面板上）。
地图上 **↑ 通到上面一层，↓ 通回下面一层**，塔是往上爬的。
撞到墙就只是不动，不会再刷提示。

### 门、钥匙和怪怎么区分

**门是整格实心的方块**，按锁的颜色染：

- 🟡 黄门 —— 黄色实心块
- 🔵 蓝门 —— 蓝色实心块
- 🔴 红门 —— 红色实心块

钥匙跟着门用同一种颜色，图标是钥匙形状：

- 黄钥匙 —— 黄色钥匙
- 蓝钥匙 —— 蓝色钥匙
- 红钥匙 —— 红色钥匙

以前地图上三把钥匙画的都是同一个 🔑 emoji，黄钥匙和蓝钥匙长得一模一样，
根本认不出颜色；左栏的钥匙计数也是 🟡🔵🔴 这种圆点，和小怪的 🟢 撞脸。
现在钥匙改成带锁色的钥匙形状，钥匙栏写成「黄 ×1 / 蓝 ×0 / 红 ×0」，
钥匙颜色 = 门颜色，看一眼就知道该去开哪扇门。

以前门画的是 🔵 🟡 🔴 这种圆点图标，而史莱姆也是 🟢 🔵 🔴 的圆点，
两者几乎长得一样，走过去之前根本分不清前面是门还是怪。
现在门改成占满整格的实心色块，小怪还是圆脸表情图标，一眼就分得开。
门开过之后就变回普通地板色。

## 数值是倒推出来的

终局面板定为 **攻击 5000 / 防御 1300**，魔王战开打前身上要有 **68000 血**，然后反推 30 层的资源预算：

```
魔王：hp 200000 / atk 2500 / def 800
玩家每回合伤害 = max(1, 5000 - 800) = 4200  →  ⌈200000/4200⌉ = 48 回合击杀
魔王每回合伤害 = max(1, 2500 - 1300) = 1200  →  反击 47 次共 56400 伤害
攒够 68000 血进魔王房 → 打完剩 11600
（血量没有上限，也没有"回满"这回事：开打前有多少血，全看你一路攒了多少）
```

剩下的那 11600 血（约 17%）是刻意留的：魔王战必须掉一大截血，
但不能打到只剩一口气，不然整趟塔的时间投入就没意义了。

### 武器和防具各 5 档

剑和盾都是**取最高档**的：拾到低档不生效，同档也不生效，
所以早期那把铁剑不是白捡的 —— 它在拿到钻石剑之前是真的在顶着用。

基础面板是 **攻击 100 / 防御 50 / 生命 800**。
塔里的血量**没有上限**，只有一个数字：捡结晶把它加上去，打怪把它减下来。

每层一枚 **生命结晶**（锁在上锁的房里，小鬼守着）给的数是这么定的：

    结晶给的血 = 这一层要挨的打 + 这一层的净增长

"要挨的打"是参考路线在这一层实测掉的血，"净增长"是打完这一层、血量比刚进来时多出来的那部分
（1~25 层每层 +100，26~29 层每层 +200，末层 +8200，合计 +67200）。
两项一加，捡完结晶的血量正好等于"下一层进场时的血量"，所以血量曲线一路只涨不跌：
刚进第 30 层是 59800 血，打完第 30 层剩 68000 —— 正好是魔王战要用的那 68000。

守关怪数值也是按"该层玩家打完本层装备后的面板"倒推的：
每场大约吃掉当前血量的 18%，3~12 回合打死，打输不会直接秒，
但一场接一场打会撑不住 —— 要么靠这一层的生命结晶把血加回来，要么取舍。

塔里的怪变多、也变强了，所以守关怪的血量整体 **×1.25**（第 1 层的绿史莱姆从 2256 涨到 2820），
每层另外有 3 只看门怪（两只小鬼、一只史莱姆；剑和盾那间也站了一只小鬼）。
小怪的数值不在表里手写，而是从本层守关怪按比例派生：
小鬼血 35% / 攻 45% / 防 60% / 掉金 30%，史莱姆血 18% / 攻 25% / 防 40% / 掉金 15%。
小怪便宜、掉血少，但让每层都有事可干。

**巡逻怪**是第三种怪，数值不从守关怪派生，而是直接按
"**刚踏上这一层时的面板**"倒推 —— 也就是玩家进层那一刻的攻击、防御和血量：

    怪物防御   = 进入时攻击 × 8%
    怪物血量   = (进入时攻击 − 怪物防御) × 5      ← 保证打 5 个回合
    每回合掉血 = 进入时血量 × 0.7% ÷ 4                ← 玩家先手，只挨 4 下

所以巡逻怪**每场吃掉进入时血量的 0.7%、打 5 个回合**，不管哪一层。
进层那一刻一定打得过（不会一进层就被秒），打完之后掉的血也刚好接得上，
不至于让一路走一路卡住。每层 26 只，走到哪里都要打。

怪一下子多了五倍，**每一场的伤害就得摊薄**，不然一层掉的血会翻五倍：
巡逻怪从原来的 8% 降到 0.7%，守关怪还是 18%，
所以一层 30 场仗打下来，掉的血和以前差不多 —— 变的是节奏，不是难度。
金币也一样：一只守关怪现在只占三十只怪里的一只，掉的金币摊成原来的 1/4，
塔里金币的总量还是六万六千多。

## 战斗怎么结算

回合制，玩家先手，双方每回合各打一下，伤害最低 1 点（`max(1, 攻 − 防)`）。
塔里没有药，所以战斗只有两条硬规矩：

- **血量只会往下掉**。打完之后的血量一定不高于开打时，不会越打越多。
- **打不赢就是打不赢**。血量一路掉到 0（然后你会死，按 `U` 撤销或读取存档能回到开打前）。
  没有药能续命，也没有"濒死自动喝药"这回事。

魔王战开打前身上是 68000 血（这一路捡结晶攒出来的），
48 个回合打下来正好剩 11600。

## 加血只有即时性

塔里**没有药水**：地上不摆药瓶，背包装不下药，
攒不出"以后再喝"的那口血。血量也**没有上限**，从头到尾只有一个数字：

- **生命结晶**（每层一枚，锁在上锁的房里，小鬼守着）：直接加血，给多少加多少。
  日志写「获得 生命结晶（生命 +970，现在 1770）」。
- **商店里的疗伤丹**：买了当场回血，不进背包（见下面「商店和金币」）。

推开魔王房的门**不再回血** —— 没有上限，就没有"满"可回，
魔王战开打前有多少血，全看你一路攒了多少。

所以整条通关路线上血量只会往下掉，只有捡结晶这一步会往上涨 ——
校验器把这条单独断言了（`整条通关路线上血量只会往下掉（只有捡生命结晶会涨）`）。
## 怪物图鉴

第 1 层出口（通往第 2 层那扇门的外面）躺着一本 **📖 怪物图鉴**，
走过去就捡进背包，捡到的那一刻面板会自动翻开。

翻开之后是一张表，**只列当前层有的怪**：本层 1 只守关怪 + 3 只看门怪 + 巡逻怪，末层还多 1 只魔王。
同一层的几只巡逻怪长得一样，图鉴里合并成一行。

以第 1 层为例（刚开局，面板还是 100/50/800，背包还是空的）：

| 怪物 | 血量 | 攻击 | 防御 | 金币 | 战斗结论 |
|---|---|---|---|---|---|
| 👺 洞穴小鬼 | 987 | 41 | 14 | 9 | 损失 11 点血量 |
| 🟢 绿史莱姆 | 2820 | 92 | 24 | 29 | 不可战胜 |
| 🟢 青苔史莱姆 | 508 | 23 | 10 | 4 | 损失 5 点血量 |
| 🐺 巡逻土狼 | 460 | 52 | 8 | 7 | 损失 8 点血量 |

这一层没有怪的时候就是一句"这一层没有怪物"，不列别层的怪 ——
翻起来看到的都是这一场用得上的数字。

最后一列是**按你当前面板算出来**的结论，三档：

- **不可战胜** —— 这场仗怎么打都赢不了，硬冲就是死
- **无伤击杀** —— 一回合就拿下，怪来不及还手
- **损失 XXX 点血量** —— 具体的掉血数字

面板一变，结论跟着变（升了攻击之后，原本"损失 3000 点血量"的怪会变成"无伤击杀"）。
这张表用的是同一份结算函数，所以和你真打的时候结果一致：
图鉴写"不可战胜"的怪，撞上去是真的会死；写"损失 N 点血量"的怪，
打完就真是掉 N 点左右。

捡到之后书一直在背包里，按 `B` 随时能再翻出来，也可以点背包里的条目打开，
`Esc` 合上。图鉴面板开着的时候数字键不做事，避免误触。

## 传送卷轴

第 **15 层**有一个 **📜 传送卷轴**，走过去捡进背包。

它不是踩上去就弹面板那种固定设施，而是一件随身带着的东西：

- 背包里有卷轴，并且人**站在楼梯格上或紧挨着楼梯格**时，按 `↑` 就上一层、按 `↓` 就下一层
- 落点在目标层楼梯**旁边的一格**（不站在楼梯上），落下去接着走就行
- **条件不满足的时候完全不出任何提示**：不在楼梯旁边就没有任何反应，
  按键该怎么走还是怎么走；日志里也不会多一行字
- 卷轴不会消耗，可以一直用

在楼梯旁边按 `↑`，日志里会出现一行 `📜 传送卷轴：第 16 层 · 机械圣所`，
所以不会莫名其妙就换层了。

效果上它替代了以前那三个 🌀 跨层阶梯（原来能跳上下 10 层）。
现在想快速上下楼，站在楼梯旁边按方向键就行，不用记哪层有阶梯。

## 商店和金币

商店在第 **6、10、14、18、22、26、29** 层，一共 7 家。
每家只卖三样东西，买下**当场生效**，不进背包：

| 键 | 商品 | 买一次加什么 |
|---|---|---|
| 1 | 💊 疗伤丹 | 生命值直接加上去 |
| 2 | 🪨 磨刀石 | 攻击力**永久**加到面板上 |
| 3 | 🔰 护心镜 | 防御力**永久**加到面板上 |

四条规则：

- **没有库存限制**，想买多少次买多少次；
- **越高层加得越多**：第 6 层的商人给一份量，第 29 层给七份量；
- **每家商店自己一套价目表**：在第 6 层买过几次，不影响第 10 层那家的起步价；
  同一家店里三项也各算各的（买了磨刀石不影响疗伤丹的价格）；
- **同一家店里连买同一项，价格按 1.6 倍往上走**（不是等差，是等比），买得越多越贵。

每家商店卖什么、起步价多少：

| 商店 | 加血 | 加攻 | 加防 |
|---|---|---|---|
| 第 6 层 | +1000 血 / 260 金 | +50 攻 / 325 金 | +25 防 / 390 金 |
| 第 10 层 | +2000 血 / 500 金 | +100 攻 / 625 金 | +50 防 / 750 金 |
| 第 14 层 | +3000 血 / 720 金 | +150 攻 / 900 金 | +75 防 / 1080 金 |
| 第 18 层 | +4000 血 / 920 金 | +200 攻 / 1150 金 | +100 防 / 1380 金 |
| 第 22 层 | +5000 血 / 1100 金 | +250 攻 / 1375 金 | +125 防 / 1650 金 |
| 第 26 层 | +6000 血 / 1260 金 | +300 攻 / 1575 金 | +150 防 / 1890 金 |
| 第 29 层 | +7000 血 / 1400 金 | +350 攻 / 1750 金 | +175 防 / 2100 金 |

连买的价格 = 起步价 × 1.6^(在这家店已经买过几次)，四舍五入到整金。
所以在第 6 层连买三次加血，价格是 260 → 416 → 666 → 1065 金。
同一家商店反复进出也接着上次继续涨 —— 计数记在这家店自己头上。

**价目表是按金币产出标定的**，不是随手拍的数字：

| 商店 | 走到时累计金币 | 一套三样各买一次 | 占家底 |
|---|---|---|---|
| 第 6 层 | 2046 | 975 金 | 48% |
| 第 10 层 | 5470 | 1875 金 | 34% |
| 第 14 层 | 10532 | 2700 金 | 26% |
| 第 18 层 | 19004 | 3450 金 | 18% |
| 第 22 层 | 31020 | 4125 金 | 13% |
| 第 26 层 | 48532 | 4725 金 | 10% |
| 第 29 层 | 61891 | 5250 金 | 8% |

越往上家底越厚，一次能买得越多，所以高层商店是花钱的主战场；
低层商人买起来最吃力，但眼下就要补血的时候也不用干等高层。
（校验器会重新扫一遍关卡，核对这个金币预算表和关卡里实际掉的金币对得上。）

按数字键或直接点都行。血量没有上限，疗伤丹什么时候买都回得动，每次买都扣钱；
金币不够会提示还差多少。

金币一共有 **66644**：守关怪 + 小怪 + 巡逻怪合计掉 45660，地上 111 格金币合计 20984。
金币没有别的用处，只能在商店花，而商店的东西越买越贵 ——
这笔钱买得到什么，取决于你打算在哪家商店、买哪几样。
几乎花光的话大约能买到 15 件（三样各买四到六次），
面板上大约 +16000 血 / +1000 攻 / +400 防。

血量没有上限，所以疗伤丹是"永久"加血 —— 买一次血就多一截；
磨刀石和护心镜则是**永久加在面板上**的，买多了魔王战会轻松得多。
花钱换一个更轻松的终局，是有意的取舍。
本 README 里"终局面板 5000 / 1300"、"魔王战前 68000 血"和"魔王战 48 回合、剩 11600"
指的是**参考路线（一样东西都不买）**。

## 关卡结构

每层固定 **13×13**，用字符地图 + 每层一份 `legend`
（覆盖全局字符表，所以同一个 `'s'` 在第 1 层是铁剑、在第 22 层是钻石剑）。

形状是 **「九间房 + 门洞」**：

- 每层 **9 间 3×3 的房**，墙在第 4 / 8 行和第 4 / 8 列
- 房间之间只在墙上开**门洞**，门洞的连法是一棵**有分叉的树**（不会绕圈，也不会一条道走到黑）
- 墙占 47.3%，平均每层空地 89 格；每层 36 处 2×2 开阔地、45 个岔口
- 3×3 的房间网格一共 192 种连法，30 层轮着来，不会长一个样
- 格子是直角，墙看过去是一块块方方正正的黑砖，不会出现三角形的缺口

**上锁的房**每层 5 间 —— 4 个角 + 正中间，彼此不相邻，所以门不会撞车：
往上那级楼梯（末层是魔王）、开门钥匙、生命结晶、
商店 / 传送卷轴 / 备用钥匙、剑或盾。

几条"卡点"是被几何强制的，不是靠约定：

```
守关怪站在钥匙房的门洞上，钥匙在房间正中间；
门站在上楼房的门洞上，上楼楼梯就在门正后方一格（末层是魔王）；
小鬼和史莱姆守在结晶房、杂物房、装备房的门洞上；
巡逻怪散在房间里（房角 / 房中心），门洞留给看门怪。
```

- 把所有怪挡住 → 拿不到能开本层门的钥匙（校验器逐层断言）
- 把所有门和怪封死 → 到不了往上爬的楼梯（校验器逐层断言）
- **两只怪不会挨着**：正交相邻的怪对数必须是 0（校验器逐层断言）
- 看门怪（守关怪 + 3 只小怪，共 120 只）必须站在门洞上
- 巡逻怪（共 780 只）必须在房间里，或者是上锁房间多出来的那个门口
- 本层门的钥匙只有一把，就在守关怪后面；每层还多一把**楼上那层门的备用钥匙**
  （颜色和本层门不同），留着后面用

地图是用算法刻出来、再把守关怪/门/奖励位置钉进去，最后冻结成静态字符图的
（`levels.js` 里就是最终结果，可以直接手改）。
关卡方案（哪层放什么、数值多少）写在 `tools/gen-levels.mjs` 里，
跑一次 `node tools/gen-levels.mjs 20261121` 就能重新刻一遍整座塔。

## 三层架构

```
表现层  js/view/*      只把 state 画出来，不含任何规则
规则层  js/core/*      step(state, action) -> { state, events }，唯一改变世界的地方
数据层  js/data/*      关卡地图 + 道具/怪物图鉴
```

| 文件 | 职责 |
| --- | --- |
| `js/data/tiles.js` | 地图字符 → 格子对象对照表 |
| `js/data/items.js` | 道具图鉴（数值/文案/价格/档位） |
| `js/data/monsters.js` | 怪物图鉴 |
| `js/data/levels.js` | 30 层关卡 + 每层图例 |
| `js/data/balance.js` | 全塔数值底表（剑盾档位、每层结晶、商店价目表） |
| `js/core/state.js` | GameState 结构与克隆（含基础属性与装备槽） |
| `js/core/effects.js` | Effect 执行器：钥匙/装备/生命/金币/商店/战斗 |
| `js/core/battle.js` | 回合制战斗结算（纯函数）+ 战斗预判 |
| `js/core/reducer.js` | 状态转移函数（含商店 BUY、图鉴开关、传送卷轴判定） |
| `js/view/*` | 地图、状态栏、装备栏、日志、商店面板、图鉴面板 |
| `js/ui/*` | 键盘输入、本地存档 |
| `tools/verify.js` | 结构校验 + 无头求解器 |
| `tools/gen-levels.mjs` | 关卡生成器：按方案刻出 30 层地图并写回 levels.js |
| `tools/serve.py` | 本地静态服务器（自动选端口、多线程、只监听 127.0.0.1） |
| `tools/build-single.mjs` | 把整个游戏打包成单文件 HTML |
| `dist/魔塔-单文件版.html` | 生成物：双击即玩的单文件版 |

## 为什么这样拆

- **关卡只写字符，数值全在图鉴表**：调平衡不用碰关卡文件。
- **Effect 统一抽象**：门、怪物、商店、机关都只是"触发一串效果"，规则层只有一条执行路径。
- **reducer 是纯函数**：存档 = 序列化 state；撤销 = 状态栈；
  测试 = 不渲染就能跑（求解器就是这么来的）。
- **一次性的格子效果记在 `state.taken`**：踩过的道具/怪物不会重复结算。
- **装备槽只存最高档**：`state.gear.weapon/armor` 各存一份，
  攻防由 `BASE_STATS + 当前档位` 算出来，所以低档拾取天然无效。
- **战斗预判是纯函数**：`previewFight(玩家, 怪物)` 不碰状态，
  规则层和图鉴面板共用同一份计算，不会出现两套数字对不上。

## 已实现的规则

- 战斗：双方每回合互殴一次，伤害 = `max(1, 攻击 - 防御)`，玩家先手，怪物死后不再反击。
- 怪物：每层 30 只（守关怪 1 + 看门怪 3 + 巡逻怪 26），全塔 900 只；
  看门怪守在门洞上（身后是上锁的房），巡逻怪散在房间里；
  **任何两只怪都不挨着**，路上不会出现「一格接一格全是怪」。
- 没有药：道具表里没有药水，地图上没有药瓶，背包里装不下药。
- 血量没有上限，只有一个数字：捡到生命结晶（直接加血）、
  商店里的疗伤丹（买了立刻回，不进背包）。
- 商店：第 6、10、14、18、22、26、29 层各有一家，每家只卖加血 / 加攻 / 加防三项。
  买下当场生效、不进背包、没有库存限制；越高层加得越多，
  每家商店自己一套价目表（各店独立计价），
  同一家店里连买同一项按 1.6 倍等比涨价。
- 门：黄/蓝/红三种钥匙门；开过的门记在 `state.openDoors`，不再重复扣钥匙。
- 楼层：每层一张地图，踩 `↑` 通到上面一层、踩 `↓` 通回下面一层，
  落点落在对层楼梯旁边的一格（不站在楼梯上）。
- 传送卷轴：第 15 层拾取，背包里有卷轴且人在楼梯上/紧邻楼梯时，
  `↑` 去上一层、`↓` 去下一层，落点同样在目标层楼梯旁边一格；
  不满足条件时静默，按键退化成普通移动。
- 怪物图鉴：踩到书自动翻开并入包，之后按 `B` 或点背包条目随时重开，只列当前层的怪。
- 撞墙：不移动，也不出任何提示。
- 存档：每次成功移动后自动写入 localStorage；阵亡时不会覆盖存档，
  所以"读取存档"可以回到阵亡前那一刻。

## 拿去改着用

**MIT 许可证**（见 [LICENSE](LICENSE)）：随便拿去改 —— 改关卡、改数值、改界面、改玩法都行，
教学、写课程作业、或者自己往上加一层都可以。

动手前先看两处：

- **关卡只写字符**：每层地图是一张字符画，怪物、道具、门、楼梯都是字母，
  数值全在图鉴表里。调平衡不用碰地图文件。
- **规则层是纯函数**：`js/core/reducer.js` 里的 `step(state, action)` 是唯一改变世界的地方，
  不碰 DOM。改完可以直接跑 `node tools/verify.js`，让求解器替你走一遍 30 层，
  改坏了它会告诉你哪条断言挂了。

改完源码想生成新的单文件版，跑一次 `node tools/build-single.mjs`，
新的 `dist/魔塔-单文件版.html` 就是双击即玩的版本。

CI 红了不是给你添堵 —— 那是求解器在告诉你这次改动把塔改坏了。
